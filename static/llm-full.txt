# Emmanuel Yeboah — Backend & Payments Engineer for African Fintech

> Independent backend and payments engineer. https://noelzappy.dev · @noelzappy · me@noelzappy.dev

## Summary

Independent backend engineer for companies moving money in Africa. I build and fix payment integrations, ledgers and zero-downtime migrations — MoMo, Paystack, Flutterwave, Hubtel. Six years on correctness-critical systems. Based in Accra, Ghana; works remotely (GMT, with overlap for European and US East Coast hours).

## Timeline

- Now — Independent consultant. Payments, ledgers and migrations for fintech teams. Writing about systems.
- 2025–present — SusuPaa. Co-founder and CTO (Pavex Technologies). Built the platform and its custom append-only ledger, the system of record for ₵12.5M+ in successful deposits. Cut p99 API latency from 1.6s to 500ms.
- 2024–2025 — Fetch Agent. Backend engineer (contract). Built the agent-ranking and filtering engine that matches buyers to agents, and the APIs behind the app and admin dashboard, held under 200ms.
- 2024–2025 — RBL Matchmaking. Lead engineer. Zero-downtime migration of 170,000 live users from PHP/MySQL to Node.js/PostgreSQL; real-time messaging for 200,000 monthly actives.
- 2024 — Hubtel. Frontend engineer. Led frontend for Hubtel for Hospitals; contributed to GHQR.
- 2023–present — The Brifcast Ltd. (Brif). Co-founder & Managing Partner. Media company telling the stories of African founders, with an editorial side and a small production studio. I run the business side (partnerships, client work, operations) and built the internal tools we use.
- 2021–2024 — Built Financial Technologies. Mobile app developer. Shipped the web platform, two React Native apps, one offline-first, and an HR platform.
- 2019–2021 — Wordnox. Founder (company closed). WordPress sites for clients.
